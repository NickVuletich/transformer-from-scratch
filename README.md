# Transformer From Scratch

Implementing the mathematics behind the Transformer architecture from scratch using NumPy.
This project focuses on understanding the linear algebra and core mechanisms behind attention rather than relying on high-level frameworks.

Modern AI models like GPT and BERT rely on the Transformer architecture.
While frameworks like PyTorch provide high-level implementations, this project rebuilds the core components from scratch using NumPy in order to deeply understand the mathematics behind attention and transformer blocks.
